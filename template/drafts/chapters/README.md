# Chapter Drafts

Organize by chapter number. Create a subfolder for each chapter and version drafts within it:

```
chapters/
├── 1/
│   ├── draft1.md
│   └── draft2.md
├── 2/
│   └── draft1.md
```

Name author-written drafts clearly to distinguish them from AI-generated drafts (e.g., `draft2-author.md`).
